# 출시 체크리스트

[07 출시 준비](README.md) · 법률 자문 아님 · 심사 기준은 미검증

## 제출 전 확인 (TestFlight, 실기기)

| 확인 | 기대 결과 |
|---|---|
| 새로 설치 후 앨범 사진 스캔 (사전 모드, 키 없음, 비행기 모드) | 단어 목록이 나온다 |
| 카메라 권한 거부 후 "카메라로 촬영" | "설정 열기" 안내가 보인다 |
| 기기 언어를 일본어·한국어·영어로 바꿔 처음 카메라를 연다 | 시스템 권한 창이 그 언어로 나온다 (한국어·일본어 외에는 영어) |
| 사진 권한 거부 상태 | 앨범 선택이 PHPicker라 권한 없이도 동작한다 |
| 단어 상세 스피커 | 일본어 읽기가 들린다 |
| 설정 → 오픈소스·라이선스 | 다섯 데이터 출처와 라이선스, 한국어 사전 데이터 링크가 보인다 |
| 설정 → 개인정보 | 정정 문구와 "개인정보 처리방침" 링크가 보이고, 링크를 누르면 게시된 전체 처리방침이 브라우저에서 열린다 (DS-20) |
| ChatGPT 모드 (본인 키) | 한국어 뜻이 채워진다. 키 삭제 후엔 메뉴가 비활성 안내로 바뀐다 |
| iOS 26 미만 기기 | 저장 바가 패널 안에 보이고, 저장 후 토스트가 뜬다 |
| Apple Intelligence 기기 | AI 모드, 한국어 뜻, 예문 생성이 동작한다 |
| 기기를 가로로 돌림 | 화면이 돌지 않는다 |
| 작은 화면 (iPhone SE 계열이 지원 대상이면) | 글자가 잘리지 않는다 |
| 사전 모드의 한국어 뜻 | AI·네트워크 없이 半額·駐車場 등 수록 단어의 한국어 뜻이 보이며, 미수록 단어는 영어로 대체된다 |
| 한국어 사전 데이터 공개 | 출처 화면의 데이터 다운로드 URL이 열리고 원본별 출처·라이선스·가공 정보를 확인할 수 있다 |
| 처리방침·지원 URL | 브라우저에서 열린다 |
| 앱 용량 | App Store Connect에 표시되는 크기 확인 (사전 DB 약 119MB) |

## 예상 반려와 대응

| 예상 사유 | 대응 |
|---|---|
| ChatGPT 기능을 쓸 수 없다 (키가 필요) | 심사 노트에 "선택 기능이며 핵심 기능은 키 없이 동작"을 적는다 ([store-listing.md](store-listing.md#심사-노트-app-review-information)) |
| 제3자로 데이터 전송 고지 부족 | 설정 개인정보 정정 문구, 처리방침의 OpenAI 항목, 개인정보 라벨로 대응 |
| 처리방침 URL이 열리지 않음 | 저장소 공개와 Pages 설정 확인 |
| 데이터 라이선스 표기 | S-13 화면과 설명 끝의 출처 표기 |
| 기능 부족 | 오프라인 OCR·사전·단어장·퀴즈가 모두 있다는 점을 노트에 적는다 |
