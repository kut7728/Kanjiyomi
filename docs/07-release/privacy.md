# 개인정보 처리 현황

[07 출시 준비](README.md) · 법률 자문 아님 · 확인 필요

처리방침은 `site/privacy/`(한국어·일본어)에 두고 GitHub Pages로 게시합니다(RL-06). 아래는 코드가 하는 일이며, 처리방침과 개인정보 라벨의 근거입니다. 자세한 기술 내용은 [04 security.md](../04-technical/security.md)에 있습니다.

## 수집·보관

| 항목 | 어디에 | 기기 밖으로 | 사용자가 지울 수 있나 |
|---|---|---|---|
| 스캔한 사진(축소본)과 인식 결과 | 기기 SwiftData | 아니오 | 예 (스캔 기록 삭제) |
| 단어장 | 기기 SwiftData | 아니오 | 예 |
| 뜻 캐시, 한자 패턴, 퀴즈 기록 | 기기 SwiftData | 아니오 | 아니오 (앱 삭제 시) |
| OpenAI API 키 | 기기 Keychain | 요청 헤더로만 OpenAI에 | 예 |
| 인식된 글자, 단어·읽기·영어 뜻 | — | ChatGPT 모드에서만 OpenAI로 | 해당 없음 |

계정·로그인, 위치, 분석·광고 SDK, 앱 운영 서버는 없습니다.

## 앱 안에서 알리는 내용

설정 탭 "개인정보" (`Kanjiyomi/Features/Settings/SettingsView.swift`):

- "글자 인식, 사전 검색, 단어장은 인터넷 없이 이 기기에서만 동작합니다."
- "사진에서 읽어낸 글자와, 그 단어의 읽기·영어 뜻을 OpenAI로 보냅니다. 사진 자체는 기기를 떠나지 않습니다." (2026-10-15 정정)
- "요청은 저장한 키로 직접 보내집니다. 저희 서버를 거치지 않습니다."

실제로는 뜻을 만들 때 단어의 읽기와 JMdict 영어 뜻도 함께 보냅니다(`MeaningService.swift`의 `MeaningRequest.promptLine`). 그래서 문구를 아래처럼 고쳤습니다 (TD-14, 사용자 확정).

| 항목 | 이전 문구 | 정정 문구 |
|---|---|---|
| ChatGPT 행 제목 | ChatGPT를 고른 경우에만 전송 | ChatGPT를 고른 경우에만 전송 (유지) |
| ChatGPT 행 설명 | 사진에서 읽어낸 글자만 OpenAI로 보냅니다. 사진 자체는 기기를 떠나지 않습니다. | 사진에서 읽어낸 글자와, 그 단어의 읽기·영어 뜻을 OpenAI로 보냅니다. 사진 자체는 기기를 떠나지 않습니다. |

## App Store 개인정보 라벨

RL-10 (사용자 확정, 2026-10-15). App Store Connect 항목 이름은 바뀔 수 있습니다 (미검증).

| 항목 | 입력 |
|---|---|
| 데이터 수집 여부 | 예 |
| 데이터 유형 | 사용자 콘텐츠 → 기타 사용자 콘텐츠 |
| 사용 목적 | 앱 기능 |
| 사용자와 연결 | 아니요 |
| 추적에 사용 | 아니요 |

근거: ChatGPT 모드에서 인식된 글자와 단어 정보가 제3자(OpenAI)로 전송됩니다. 계정이 없고 앱이 식별자를 붙이지 않으므로 사용자와 연결하지 않습니다. 같은 내용을 `PrivacyInfo.xcprivacy`에도 적습니다(TD-20).

## 제3자 제공 고지

처리방침에 "ChatGPT 모드를 고르면 사용자가 입력한 OpenAI 키로 OpenAI에 직접 전송되며, OpenAI의 정책이 적용된다"고 적습니다. 앱 안에서는 설정의 개인정보 안내(정정 문구)로 알립니다.
