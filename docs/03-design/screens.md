# 화면별 구성

[03 화면 설계](README.md) · 화면 ID는 [screen-flow.md](screen-flow.md)

따옴표 안 문구는 코드에 있는 실제 문구입니다.

## S-01 스캔 홈

```
┌──────────────────────────────┐
│ 스캔                          │
│ ┌──────────────────────────┐ │
│ │ 사진으로 인식              │ │
│ │ 카메라로 찍거나 앨범에서…   │ │
│ │ [ 카메라로 촬영 ]          │ │
│ │ [ 앨범에서 선택 ]          │ │
│ └──────────────────────────┘ │
│ 인식 기록               3개   │
│ [썸네일] 本日 · 限定 · …  23   │
│          2026년 10월 4일 …    │
└──────────────────────────────┘
```

- 카드 안내: "카메라로 찍거나 앨범에서 올리면 온디바이스로 일본어를 분석합니다."
- 기록 행: 56pt 썸네일, 앞 단어 4개를 " · "로 이은 미리보기(없으면 "단어 N개"), 날짜(`ko_KR`, "yyyy년 M월 d일 a h:mm"), 단어 수.
- 행 탭 → 그 스캔을 다시 연다. 오른쪽에서 끝까지 밀면 "삭제".

| 상태 | 화면 |
|---|---|
| 기록 없음 | "아직 인식한 사진이 없어요." |
| 카메라 없음 | "카메라로 촬영"이 앨범을 연다 |
| 카메라 권한 거부 | 알림 "카메라 접근이 꺼져 있어요" / "설정에서 Kanjiyomi의 카메라 접근을 켜면 바로 촬영할 수 있어요. 앨범에서 사진을 골라도 돼요." / "설정 열기"·"앨범에서 선택"·"취소" (DS-12). 처음 누를 때는 시스템이 권한을 묻는다. 앨범은 PHPicker라 권한이 필요 없다 |

## S-02 스캔 결과

[스크린샷](screenshots/highlight.png)

- 위: 둥근 사진. 아래: 단어 패널(위쪽 모서리 24). 처음엔 패널이 펼쳐져 있다.
- 패널 머리: "인식된 단어" + "N개". 뜻 생성 중이면 스피너와 "뜻 생성 중".
- 행: 왼쪽에 표제어·읽기, 오른쪽에 뜻·한글 발음. 고른 행은 파란 테두리 2pt.
- 행 탭 → 그 단어 선택, 패널 접기, 사진을 단어 위치로 확대(여백 28, 최대 6배). 같은 행을 다시 탭하면 선택 해제.
- 행 0.45초 길게 누르기 → 표제어 복사, 토스트 "「…」 복사됨".
- 선택한 단어가 나온 모든 위치에 반투명 파란 박스. 첫 위치 위에 뜻 말풍선. 말풍선 탭 → S-06.
- 패널: 손잡이·머리를 끌거나, 펼친 상태에서 목록 맨 위에서 아래로 당기면 접힌다. 60pt 넘게 끌면 상태가 바뀐다.

**툴바**

| 버튼 | 보이는 조건 | 동작 |
|---|---|---|
| 홈 (chevron.left) | 항상 | 스캔을 닫고 S-01 |
| 영역 선택 (올가미) | 사진이 있고, 처리 중이 아니고, 단어가 있을 때. 영역이 있으면 아이콘이 바뀜 | S-05 |
| 단어 나누기 (현재 모드 아이콘) | 사진이 있고, 처리 중이 아니고, 쓸 수 있는 모드가 2개 이상일 때. 뜻 생성 중엔 비활성 | 아래 메뉴 |

**단어 나누기 메뉴**

```
이 기기에서 처리
  ✓ 사전으로 나누기
    AI로 나누기              ← iOS 26 + 기기 모델 사용 가능할 때만
내 API 키로 요청 · 요금 발생   ← 키가 있을 때
    ChatGPT로 단어와 뜻 만들기
(키가 없으면) 설정에서 API 키를 넣으면 ChatGPT도 쓸 수 있어요  ← 비활성
```

모드를 고르면 같은 사진을 다시 인식합니다. 결과가 비면 "다시 인식한 단어가 없어요. 기존 결과를 그대로 둘게요."를 보여 주고 이전 결과를 둡니다. ChatGPT로 만든 스캔은 다시 열어도 다시 생성하지 않습니다.

**단어장 저장** (화면의 단어가 저장 전이고, 한국어 뜻이 하나 이상 있을 때)

| OS | 화면 |
|---|---|
| iOS 26 이상 | 탭 바 액세서리 "단어장에 저장 전" + "저장" → 확인 창 "인식된 단어를 단어장에 저장할까요?" / "저장"·"취소" |
| iOS 18~25 | 패널 안 "아직 단어장에 저장하지 않았어요" + "저장" → 바로 저장, 토스트 "단어장에 N개 저장됨" 또는 "이미 단어장에 있는 단어예요" |

안내 문구: ChatGPT 모드는 "ChatGPT가 만든 뜻으로 기존에 저장된 뜻을 덮어씁니다", 그 밖은 "이미 단어장에 있는 단어는 그대로 둡니다". 영역이 있으면 앞에 "선택한 영역의 N개만 저장합니다 · "가 붙습니다.

**영역이 있을 때**: 단어를 고르지 않은 상태면 영역 밖을 어둡게(검정 0.35) 하고 윤곽선을 그립니다. 패널 위에 "선택한 영역의 단어만 보고 있어요" + "전체 보기".

| 상태 | 화면 |
|---|---|
| 처리 중 | 화면을 어둡게(검정 0.25) 하고 로딩 카드. 문구 순서: "사진을 준비하고 있어요" → 모드별("사진에서 글자를 찾고 있어요" / "AI가 단어를 나누고 있어요" / "ChatGPT가 단어를 나누고 있어요") → "사전에서 뜻을 찾고 있어요" |
| 단어 없음 | "인식된 일본어 단어가 없습니다. 다른 사진을 시도해 보세요." (빨간 글자) |
| 목록 비어 있음 | "아직 표시할 단어가 없어요." / 영역이 있으면 "선택한 영역 안에는 단어가 없어요." |
| 이미지 오류 | "이미지를 처리할 수 없습니다." |
| ChatGPT 오류 | [04 api-spec.md 오류 표](../04-technical/api-spec.md#오류) |

## S-05 영역 선택

- 검은 배경, 다크 모드 고정.
- 머리: "취소" / "영역 선택" + 요약("사진 전체" 또는 "영역 N개 · 단어 M개") / "적용".
- 한 손가락: 자유 곡선 그리기(점 3개 이상, 그리는 중엔 흰 점선). 두 손가락: 확대·이동(최대 6배). 두 번 탭: 3배 확대 전환.
- 단어 박스가 실시간으로 바뀐다: 안쪽은 파란 강조, 바깥은 흰색 0.5 윤곽.
- 아래 안내: "한 손가락으로 원하는 부분을 감싸듯 그려 주세요. 네모가 아니어도 되고, 여러 번 그려서 영역을 더할 수 있어요. 두 손가락으로는 사진을 확대하거나 움직입니다."
- 도구: "되돌리기", "전체 지우기", "원래 크기" (쓸 수 없으면 0.4 투명).
- 아무것도 그리지 않고 "적용"하면 영역을 없앤다.

## S-06 단어 상세

[스크린샷](screenshots/detail.png) · 제목 "단어 상세"

1. **표제어 카드**: 표제어(40pt) + 복사 버튼(1.4초간 체크 표시, 토스트), 읽기, 스피커 아이콘 + 한글 발음, 품사(한국어). 스피커(한글 발음 줄)를 누르면 읽기를 일본어 음성(`ja-JP`)으로 들려준다. 읽기가 없으면 표제어를 읽는다. 무음 모드에서도 들리고, 다른 앱 소리는 재생 중에만 줄인다 (DS-11).
2. **뜻**
3. **한자 패턴** (표제어에 한자가 있을 때, `KanjiPatternSection.swift`)
   - 예외 단어: "통째로 기억하는 단어" + "패턴으로 읽기 어려운 단어입니다. 단어 전체를 하나의 표현으로 기억하는 것을 추천합니다."
   - 그 밖: "한국 한자어"(한국어 / 일본어 / 읽기), "구성 한자"(한자 → 한국 한자음 → 읽기, 음독·훈독), "같은 한자가 쓰인 단어"(한자마다 저장한 단어 최대 4개 "학습함", 사전 단어 최대 4개 "새로 볼 단어"·"아직 안 배움"), 훈독 단어면 안내.
   - 이 단어로 어떤 패턴의 단어 수가 정확히 2가 되면 "새로운 패턴을 발견했습니다" 카드.
4. **예문**: 저장된 예문을 보여 준다. 없고 기기 모델을 쓸 수 있으면 "예문을 만들고 있어요"와 함께 만든다. 못 만들면 "예문이 아직 없어요."
5. **"이 단어가 나온 스캔 보기"**: 저장한 단어에 스캔 연결이 있고 그 스캔이 남아 있을 때만.
6. **"단어장에 저장"** 버튼 또는 초록 글자 "단어장에 저장됨".

## S-07 단어장

[스크린샷](screenshots/vocabulary.png)

- 행: 표제어, 한글 발음(파랑), 뜻(회색, 2줄까지). 탭 → S-06.
- 툴바 왼쪽 "선택" → 편집. 편집 중 "완료", "전체 선택"/"전체 해제".
- 툴바 오른쪽: 개수("N개", 패턴이 있으면 "N단어 · 패턴 P") + 사전 검색 버튼. 편집 중엔 "삭제"(선택 없으면 비활성).
- 편집 중 제목: "항목 선택" / "N개 선택됨". 일괄 삭제 확인: "N개 단어를 삭제할까요?"
- 행을 오른쪽에서 끝까지 밀면 "삭제".

| 상태 | 화면 |
|---|---|
| 비어 있음 | 책갈피 아이콘, "아직 저장한 단어가 없어요", "사진을 스캔하면 인식된 단어가 여기에 담겨요." |

## S-08 사전 검색

- 검색창 "일본어 단어 또는 영어 뜻". 입력 후 0.25초 뒤 검색.
- 행: 표제어, 한글 발음, 한국어 뜻(없으면 영어, 2줄까지). 탭 → "단어를 불러오는 중" → 한국어 뜻이 없으면 만들고 → S-06.

| 상태 | 화면 |
|---|---|
| 입력 전 | "단어를 검색해 보세요" + "한자·가나 또는 영어 뜻으로 찾을 수 있어요." |
| 결과 없음 | "검색 결과가 없어요" + 같은 안내 |

## S-09~S-11 퀴즈

[스크린샷](screenshots/quiz.png)

**S-09 설정**: 모드 세그먼트("단어 → 뜻" / "뜻 → 단어" / "읽기 추론"), 안내("단어장 N개로 최대 10문제를 출제합니다." 또는 "익힌 한자 패턴으로 처음 보는 단어의 읽기를 추론합니다."), 패턴 진행 카드("익힌 읽기 패턴" N개), "퀴즈 시작".

**S-10 문제**: "i / n", "점수 s", 문제 카드, 보기 4개. 답하면 정답은 초록, 고른 오답은 빨강. "다음" / 마지막은 "결과 보기".
- 뜻 모드는 최근 틀린 단어와 같은 한자가 들어간 저장 단어를 맨 앞에 한 문제 넣을 수 있다: "같은 한자가 들어간 단어", "틀린 단어와 같은 한자를 다시 보는 보조 문제입니다."
- 읽기 추론: "{단어}은 어떻게 읽을까요?", 맞히면 "배운 적 없는 단어를 한자 패턴으로 맞혔습니다."

**S-11 결과**: "퀴즈 결과", "s / n", 점수별 문구(80% 이상 "훌륭해요! 거의 다 맞췄어요." / 50% 이상 "좋아요. 한 번 더 복습해 볼까요?" / 그 밖 "괜찮아요. 단어장을 다시 보고 도전해 보세요."), 패턴 진행 카드, "다시 풀기", "모드 선택으로".

| 상태 | 화면 |
|---|---|
| 뜻 모드, 단어 4개 미만 | "뜻 퀴즈는 단어가 4개 이상 필요해요." + 시작 버튼 비활성 |
| 읽기 추론, 문제를 만들 수 없음 | 전구 아이콘, "아직 발견한 패턴이 없어요", "같은 한자가 들어간 단어를 더 모아 보세요. 패턴이 보이면 처음 보는 단어의 읽기를 추론할 수 있습니다.", "모드 선택으로" |

## S-12 설정

- **OpenAI API 키**
  - 키 없음: 보안 입력칸 "sk-..." + "키 저장"(비어 있으면 비활성). 안내 "platform.openai.com에서 발급한 본인 키를 넣어주세요. 키는 이 기기의 키체인에만 저장되고, 백업이나 다른 기기로 옮겨지지 않습니다."
  - 키 있음: "저장된 키" ••••••••+끝 4자리, "키 삭제" → 확인 "저장된 API 키를 삭제할까요?". 안내 "키는 이 기기의 키체인에만 저장됩니다. 백업이나 다른 기기로 옮겨지지 않고, 잠금이 풀린 상태에서만 읽힙니다."
- **모델** (키가 있을 때만): 입력칸, 안내 "비워두면 gpt-5.6-luna을 사용합니다."
- **개인정보** (3행)
  - "기본은 기기 안에서 처리" — "글자 인식, 사전 검색, 단어장은 인터넷 없이 이 기기에서만 동작합니다."
  - "ChatGPT를 고른 경우에만 전송" — "사진에서 읽어낸 글자와, 그 단어의 읽기·영어 뜻을 OpenAI로 보냅니다. 사진 자체는 기기를 떠나지 않습니다." (TD-14)
  - "요금은 본인 계정에 청구" — "요청은 저장한 키로 직접 보내집니다. 저희 서버를 거치지 않습니다."
- **정보**: "사용 방법·모드 안내" → S-14, "오픈소스·라이선스" → S-13

## S-14 사용 안내 온보딩 (DS-15, DS-16)

[기본 사용](screenshots/onboarding.png) · [모드 비교](screenshots/onboarding-modes.png) · [GPT 안내](screenshots/onboarding-api.png). 3단계의 스크롤 가능한 화면과 하단 이전·다음 버튼을 사용한다. 큰 글씨·작은 화면에서도 본문을 스크롤하고 버튼을 사용할 수 있다. 첫 실행에 표시하며 기존 사용자도 완료 플래그가 없으면 한 번 표시한다. 설정 → "사용 방법·모드 안내"에서 다시 볼 수 있다.

1. **기본 사용**: 촬영·앨범 → 단어와 한글 발음·뜻 → 단어장·퀴즈. `半額 / はんがく / 한가쿠 / 반값`은 설명용 예시다. 키 없이 오프라인 사용 가능, 한국어 사전은 일부 단어만 수록, 미수록 단어는 AI 보완이 안 되면 영어 뜻으로 표시, 한국어 뜻이 있는 단어만 단어장에 저장 가능함을 알린다. 현재 기기의 온디바이스 AI 사용 가능 여부를 표시한다.
2. **모드 비교**: 실제 메뉴 명칭을 함께 표시한다. 사전은 사전 수록 단어로 분리하고 한국어 미수록 뜻은 온디바이스 AI가 가능할 때 보완한다. 온디바이스 AI는 사전 밖 단어의 분리·뜻과 새 예문 생성에 사용되며 iOS 26+ 및 Apple Intelligence 이용 가능 상태가 필요하다. ChatGPT는 인터넷·본인 API 키가 필요하고 사전 밖 단어·한국어 뜻을 보완한다. OCR은 세 모드 모두 기기에서 동일하게 처리한다. 이 화면은 모드 선택기가 아니다.
3. **GPT 안내**: Apple Intelligence를 쓸 수 없는 기기의 한국어 뜻 보완 장점, 키 저장만으로 요청하지 않는 점, 사진 인식 후 "단어 나누기"에서 ChatGPT를 직접 선택하는 방법을 설명한다. ChatGPT 구독과 별도인 API 사용 요금, 원본 사진을 제외한 인식 텍스트·단어 읽기·영어 뜻 전송, 키체인 저장을 안내한다. GPT는 현재 새 예문을 생성하지 않으며 생성 결과 오류 가능성도 알린다. API 키 설정 버튼과 키 없이 시작하는 버튼을 제공한다.

상단에 단계 번호와 "나중에 보기"를 둔다. 하단은 "이전 / 다음"을 가로로 나란히 배치하고 마지막 단계는 "이전 / 바로 시작하기"로 바꾼다. 첫 단계의 이전은 비활성화한다. API 키 설정·요금 안내 링크는 마지막 본문에 배치한다. (DS-17, 반영·검증 완료)

스크롤을 줄이기 위해 큰 장식 아이콘을 제목 옆 작은 아이콘으로 바꾸고 제목·설명을 축약한다. 예시는 표기·읽기·한글 발음과 뜻을 가로 한 카드로, 모드 비교는 짧은 3개 행을 한 카드로 묶는다. 일반 글씨의 375×667pt 화면에서 세 단계 모두 본문 끝까지 스크롤 없이 보이는 것을 UI 테스트로 확인했다. 내용이 넘칠 때만 스크롤되도록 하고 글씨 크기를 강제로 축소하거나 본문을 잘라 숨기지 않는다. 비용·전송 정보·영어 대체·단어장 저장 제한·GPT 예문 미지원 안내는 유지한다.

사용 가능 여부는 화면을 열거나 앱이 다시 활성화될 때 기존 `MeaningService.isGenerationAvailable`로 확인하며, 불가를 기기 영구 미지원으로 단정하지 않는다.

DS-18의 간격 규칙: 진행바 아래부터 제목까지 32pt, 본문 묶음 사이 20pt를 두고 본문 줄 간격을 늘린다. GPT 본문의 최종 카드·행 구성은 DS-19를 따른다.

비용 안내 근거: [OpenAI의 ChatGPT·API 별도 결제 안내](https://help.openai.com/en/articles/9039756-managing-billing-settings-on-the-chatgpt-web-and-api-platform). 기기 모델 가용성 근거: [Apple SystemLanguageModel](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel).

DS-19 (반영·검증 완료): GPT 화면의 최종 본문은 2페이지 모드 비교와 같은 흰 `KYCard`에 사용 방법·요금·개인정보 3개 행을 묶고 구분선으로 나눈다. 각 행은 동일한 SF Symbol + 제목(서브헤드라인 굵게), 설명(각주), 제목·설명 간격 8pt를 재사용한다. 첫 행을 눌러 API 키 설정, 요금 행을 눌러 공식 결제 안내를 연다. 카드 밖에는 AI 예문 제한·오류 가능성 안내만 두며, 별도 원형 단계 흐름이나 배경 없는 정보 행은 사용하지 않는다. 진행바 아래 32pt 여백과 하단 가로 탐색을 유지한다.
