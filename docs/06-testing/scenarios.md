검증 결과: T-51~T-54의 페이지 이동·완료 후 재실행·API 설정 이동·재열기·닫기는 `KanjiyomiUITests` 2개가 통과했다. T-55는 iOS 26.3의 iPhone SE(3세대) 시뮬레이터(375×667pt)에서 접근성 최대 글씨 크기와 본문 스크롤·하단 탐색을 확인했다. iOS 26.5 iPhone 17 Pro에서 첫 화면 배치도 확인했다. 두 시뮬레이터의 온디바이스 AI 가용성은 사용 가능으로 감지됐으며, 불가 상태의 실기기·실제 AI 생성·유료 API 요청은 이번에 검증하지 않았다.

DS-17 추가 검증 (2026-10-16): iPhone SE(3세대), iOS 26.3, 375×667pt, 기본 글씨에서 UI 테스트 2개 통과. `testOnboardingCompletionPersists`는 각 단계 마지막 안내가 스크롤 없이 보이고 이전·다음/시작 버튼의 세로 중심이 같으며 가로로 떨어져 있는지 검증한다. sim-use로 세 단계의 전체 내용과 가로 버튼을 확인했고, 접근성 최대 글씨에서도 본문을 스크롤하면서 하단 가로 버튼을 사용할 수 있음을 확인했다.

DS-18 추가 검증 (2026-10-16): iPhone SE(3세대), iOS 26.3, 375×667pt, 기본 글씨에서 UI 회귀 테스트 2개 통과. 진행바와 제목 사이 32pt 여백, 단계별 본문 간격, GPT의 키 등록 → 사진 스캔 → GPT 선택 아이콘 흐름, 요금·개인정보 행 구분을 sim-use로 확인했다. 첫 단계 버튼을 통한 설정 이동도 통과했다. 이번 조정에서는 큰 글씨·실기기·외부 유료 API를 다시 실행하지 않았다.

DS-19 검증 (2026-10-16): GPT 본문을 2페이지와 동일한 KYCard·공통 제목/설명 행·구분선으로 통일했다. iPhone SE(3세대), iOS 26.3, 375×667pt, 기본 글씨에서 UI 회귀 테스트 2개 통과. sim-use로 2·3페이지의 카드 형태와 전체 안내 표시를 확인했다. 큰 글씨·실기기·유료 API는 이번에 다시 확인하지 않았다.
