| TS-04 | OCR, 기기 모델, ChatGPT는 자동 테스트하지 않는다 | 저장소에 해당 테스트 없음 |

| TS-06 | 한국어 데이터 파서의 복수 읽기·동음이의어·비유적 역번역 제외, SQLite 정확 조회·누락·캐시·ChatGPT 분리를 작은 fixture로 검증한다. 실제 LFS DB는 단위 테스트에서 사용하지 않는다 | 한국어 사전 도입, 구현 완료 (2026-10-15) |
