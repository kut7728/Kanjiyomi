## M11 오프라인 한국어 뜻 (완료, 2026-10-15)

- 한국어기초사전·Wiktionary 보조 DB와 재현 가능한 빌드 스크립트, 원본별 출처·라이선스 기록.
- 역번역은 일본어 표기·읽기와 영어 의미 대조, 비유적 뜻 제외, 표본 검수. 불확실한 항목은 제외.
- 스캔·사전 검색·관련 단어 상세에 한국어 뜻 연결, 캐시 출처와 ChatGPT 분리.
- 작은 fixture로 파서·조회·캐시 회귀 테스트. LFS 없는 CI에서 실제 사전 DB를 테스트에 사용하지 않음.
- 전체 사전의 뜻을 전수 검수하는 작업은 아님. 미수록 단어의 기존 영어/AI 대체 경로 유지.

검증 결과: Swift 55개(일반 사본·LFS 포인터 사본 각각), Python fixture 5개 통과. 한국어 보조 DB 23,236행·약 4.6MB 생성 및 무결성 확인. iOS 26.5 시뮬레이터에서 사전 모드 사진 스캔 8개 단어의 한국어 뜻과 상세 전달을 확인했다. 실기기·원격 CI는 이번 작업에서 확인하지 않았다.

최종 한국어 DB를 포함한 앱에서 사전 검색 `駐車場`의 행이 영어 대신 `주차장`으로 표시되는 것도 sim-use로 확인했다.

## M12 사용 안내 온보딩 (완료, 2026-10-16)

- S-14의 3단계: 기본 사용·사전 한계 / 모드 비교·현재 기기 AI 상태 / 선택적 GPT 설정·요금·전송 정보.
- 첫 실행 완료 여부를 저장하고 설정에서 다시 열 수 있다. API 키 설정 버튼은 기존 설정으로 이동하며 유료 요청이나 모드 전환을 하지 않는다.
- UI 회귀 테스트로 완료 후 재실행·페이지 이동·API 설정 이동·설정 재열기를 확인한다. sim-use로 현재 AI 상태 안내와 큰 글씨·작은 화면 스크롤을 확인한다.

검증 결과: 시뮬레이터 빌드 및 온보딩 UI 회귀 테스트 2개 통과. 375×667pt 화면과 접근성 최대 글씨 크기에서 스크롤·하단 탐색을 확인했다. AI 불가 실기기·실제 생성·유료 API 호출은 미검증. 커밋·푸시는 하지 않았다.

DS-17 화면 조정 (2026-10-16): 제목·본문·여백·예시를 압축하고 모드 비교를 한 카드로 통합했다. 하단 이전·다음/시작은 가로 배치, API 키 설정은 마지막 본문으로 이동. 기본 글씨의 iPhone SE에서 세 단계의 전체 안내가 스크롤 없이 표시되는 UI 회귀 테스트 2개 통과. 큰 글씨의 본문 스크롤은 유지한다.

DS-18 가독성 조정 (2026-10-16): 진행바 아래 여백 32pt, 본문 묶음 간격 20pt, 설명 줄 간격·제목 간격을 정돈했다. GPT 화면의 연속 문단을 3단계 아이콘 흐름과 요금·개인정보 행으로 바꾸고 키 등록 단계에서 기존 설정을 열도록 연결했다. 기본 글씨의 iPhone SE에서 무스크롤·가로 탐색·설정 이동 UI 테스트 2개 통과 및 세 화면 시각 확인. 큰 글씨 스크롤은 기존 구현을 유지한다.

DS-19 카드 통일 (2026-10-16): GPT 본문을 2페이지와 같은 KYCard 한 장·공통 제목/설명 행·구분선으로 통일했다. 별도 원형 아이콘 흐름은 제거하고 사용 순서를 첫 행에 포함했다. 키 설정·요금 안내 동작은 유지하며 SE에서 UI 회귀 테스트 2개 통과 및 시각 확인.
