# Kanjiyomi — 요구사항 스펙 (PROMPT)

**제품**: Kanjiyomi — 일본 전단지·간판 속 일본어를 단어 단위로 인식해 뜻과 발음을 알려주는 iOS 네이티브 앱 (MVP, 로그인 없음, 전부 로컬 저장)

**타겟 환경**: iOS 26+, SwiftUI, Apple Intelligence 지원 기기 (iPhone 15 Pro 이상)

**핵심 원칙**: 인식 정확성과 속도 최우선 → 100% 온디바이스 파이프라인

## 기능 요구사항

1. **미디어 인식**: 카메라 촬영 또는 사진 업로드 → 토스 스타일 로딩 → 이미지 아래로 인식된 전체 단어 리스트(뜻·한글 발음 표기) 표시
2. **영역 하이라이트**: 리스트 아이템 탭 → 이미지로 스크롤 업 → 해당 단어의 인식 영역을 박스로 하이라이트 + 영역 위 말풍선으로 뜻 표시 → 말풍선 탭 시 상세 페이지 이동
3. **상세 페이지**: 한자/가나 표기, 뜻(한국어), 한글 발음 표기, 예문 2문장(일본어+한국어 번역), 단어장 저장 버튼
4. **단어장**: 저장한 단어 목록 조회, 탭하면 상세 페이지, 삭제 가능
5. **퀴즈**: 단어장 기반 4지선다 퀴즈(단어→뜻, 뜻→단어), 결과 화면

## 디자인 시스템 (토스 스타일)

- 배경: 화이트/라이트 그레이(`#F2F4F6`), 카드: 화이트 라운드(20px) + 은은한 그림자
- 포인트 컬러: 토스 블루(`#3182F6`), 텍스트: `#191F28`(주) / `#8B95A1`(보조)
- 볼드한 타이포, 넉넉한 여백, 스프링 애니메이션, 스켈레톤/도트 로딩

## 기술 파이프라인

- **OCR**: Vision `RecognizeTextRequest`(정확도 모드, 일본어) — 온디바이스
- **단어 분리**: NaturalLanguage `NLTokenizer` + `NLTagger`(.lemma)
- **사전**: 번들 JMdict SQLite (읽기·품사·영어 뜻)
- **한국어 뜻·예문**: Foundation Models 온디바이스 LLM + SwiftData 캐시; 실패 시 JMdict 영어 폴백
- **한글 발음**: 가나→한글 결정적 매핑 테이블 (LLM 미사용)
- **저장**: SwiftData — `VocabWord`, `WordCache`

## 탭 구성

스캔(홈) / 단어장 / 퀴즈
