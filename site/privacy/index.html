Kanjiyomi는 계정이 없고, 개발자가 운영하는 서버도 없습니다. 사진 인식, 사전 검색, 단어장, 퀴즈는 모두 기기 안에서 동작합니다. 사용자가 ChatGPT 모드를 직접 고른 경우에만, 인식된 글자와 단어 정보가 사용자 본인의 API 키로 OpenAI에 전송됩니다.

제3자(OpenAI)에 전송하는 정보

사용자가 설정에 본인의 OpenAI API 키를 입력하고 스캔 화면에서 ChatGPT 모드를 고른 경우에만, 다음 정보가 OpenAI로 직접 전송됩니다.

  • 사진에서 인식한 일본어 글자
  • 단어의 표기, 읽기, 영어 뜻

사진 자체는 전송하지 않습니다. 전송된 정보는 단어를 나누고 뜻을 만드는 데에만 쓰이며, 처리에는 OpenAI의 개인정보 처리방침이 적용됩니다. 요청은 개발자 서버를 거치지 않습니다.

수집하지 않는 정보

이름, 이메일, 위치, 기기 식별자, 사용 기록을 수집하지 않습니다. 광고와 분석 도구, 추적 기능이 없습니다.

プライバシーポリシー

施行日: 2026年10月15日

概要

Kanjiyomi にはアカウントがなく、開発者が運営するサーバーもありません。写真の認識、辞書検索、単語帳、クイズはすべて端末内で動作します。ユーザーが ChatGPT モードを自分で選んだ場合に限り、認識した文字と単語情報がユーザー自身の API キーで OpenAI に送信されます。

端末内にのみ保存する情報

情報保存期間
スキャンした写真(縮小版)と認識結果ユーザーがスキャン履歴を削除するか、アプリを削除するまで
単語帳、意味のキャッシュ、漢字の読みパターン、クイズ記録ユーザーが削除するか、アプリを削除するまで
OpenAI API キー(入力した場合)端末のキーチェーン。他の端末には移行されず、設定から削除できます

これらの情報は開発者に送信されません。

第三者(OpenAI)への送信

ユーザーが設定に自身の OpenAI API キーを入力し、スキャン画面で ChatGPT モードを選んだ場合に限り、次の情報が OpenAI に直接送信されます。

  • 写真から認識した日本語の文字
  • 単語の表記、読み、英語の意味

写真そのものは送信しません。送信された情報は単語の分割と意味の作成にのみ使われ、OpenAI のプライバシーポリシーが適用されます。リクエストは開発者のサーバーを経由しません。

収集しない情報

氏名、メールアドレス、位置情報、端末識別子、利用履歴は収集しません。広告・分析ツールやトラッキングはありません。

権限

カメラは日本語を撮影するためにのみ使います。アルバムの写真は、ユーザーが選んだ写真だけがアプリに渡されます。
