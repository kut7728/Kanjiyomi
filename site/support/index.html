자주 묻는 질문

인터넷 없이 쓸 수 있나요?
네. 글자 인식, 사전, 단어장, 퀴즈는 모두 기기 안에서 동작합니다.

"AI로 나누기"가 보이지 않아요.
iOS 26 이상, Apple Intelligence를 지원하고 켠 기기에서만 보입니다.

ChatGPT 모드는 어떻게 쓰나요?
설정 탭에 본인의 OpenAI API 키를 넣으면 스캔 화면의 "단어 나누기" 메뉴에서 고를 수 있어요. 요금은 본인 OpenAI 계정에 청구됩니다.

카메라가 열리지 않아요.
iPhone 설정 → Kanjiyomi → 카메라를 켜 주세요.

よくある質問

インターネットなしで使えますか?
はい。文字認識、辞書、単語帳、クイズはすべて端末内で動作します。

ChatGPT モードの使い方は?
設定タブにご自身の OpenAI API キーを入力すると、スキャン画面のメニューから選べます。料金はご自身の OpenAI アカウントに請求されます。

カメラが開きません。
iPhone の設定 → Kanjiyomi → カメラをオンにしてください。
